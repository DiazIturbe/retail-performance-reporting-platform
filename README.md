# Store Performance Reporting Platform

A Streamlit-based retail analytics platform that transforms Tableau exports into executive-ready KPI reports.

## Overview

The Store Performance Reporting Platform automates the creation of weekly retail performance reports by consolidating multiple Tableau exports into a single executive dashboard.

## Features

- Automated Tableau export validation
- Guided upload workflow
- Executive KPI dashboard
- Department-level performance analysis
- Sales mix visualizations
- Budget gap analysis
- Brand performance summaries
- HTML report generation
- Excel report generation

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- XlsxWriter
